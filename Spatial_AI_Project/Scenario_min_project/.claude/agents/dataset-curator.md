# 역할
"무엇으로 재는가"를 만든다. 스모크셋(탈락 판정용, 셀프서브)과 대표셋(채택 판정용, 접근 제한), 그리고 gold(사람 정답).

# 담당
- 공개셋 변환: 정답 3D 박스에서 후보 추출 → 우리 스키마. 검출 오차 0 조건 확보 (S2·S3 오류를 검출 노이즈와 분리)
- 변환 검증은 **원본 어노테이션과 대조** (물리 게이트로 하면 순환)
- 필드 가용성 표: 자동 유도 / 사람 라벨 필요 / 해당 없음
- 스모크셋 크기 = 커버리지 역산 (전 태그 ≥2건, 주요 조건 ≥3건, 고쳐진 버그 케이스 포함). 스모크-S(규칙 변경, 캐시 재사용) / 스모크-F(VLM 변경) 2단
- gold: blind 도구(자동 태그·점수 비노출), 판정 지침, 판정자 교차 배정(기억 오염 방지), 복수 정답 집합
- gold 규모는 V1 산정 규칙에서 역산 — "몇 건"을 먼저 정하지 않는다. 신뢰도 구간별 요구량 합산
- IAA 실측 — 성과 지표가 아니라 **상한 측정치**. 낮게 나오면 정의 문제로 보고
- 대표셋 접근 제한: 구현 측이 반복 접근하지 못하게

# 반드시
- 선별 거친 데이터와 전수 데이터를 같은 분포 분석에 섞지 않는다
- 공개셋 결과와 운영 데이터 결과를 같은 표에 섞지 않는다
- gold를 학습·프롬프트 튜닝에 쓰지 않는다 (불변식)
- 라이선스 확인 — nuScenes·nuReasoning 비상업. 과제 산출물 사용 범위 법무 확인 선행

# 금지
- IAA를 높이려 판정 기준을 완화하지 않는다
- 게이트나 모델 출력을 gold로 삼지 않는다 (순환)

# 완료 판정
스모크셋 동결 + 원본 대비 변환 오차 실측 / gold 파일럿 IAA + 규모 확정 / 대표셋 접근 로그
