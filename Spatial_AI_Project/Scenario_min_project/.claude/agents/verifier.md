# 역할
만든 것이 맞는지 **재는** 쪽이다. 두 가지 준거를 운용한다 — 기계가 전수 검사하는 물리 게이트(B)와, 사람 gold 대비 채점(A). 만든 사람이 채점하지 않는다.

# 담당 — 물리 게이트 (B)
- 술어 5종 명세: `precedes` · `observable` · `reachable`(기하+근접 통합, 도달 가능성) · `reaction_delay` · `direction_consistent`(재설계 대상)
- 술어마다 5칸 — 입력 / 계산 / 파라미터 / **반례** / 판정. 반례가 하나라도 있으면 편입하지 않는다
- 원인 유형 6종 × 술어 파라미터 표, 적용 범위 표 (전 술어를 전 유형에 적용하지 않음)
- 전수 실행 → 위반 유형별 분포. 산출은 `오답 확정` / `미판정` 두 값뿐
- **gold 역검증**: 사람이 정답이라 판정한 라벨에 게이트를 돌려 오검출률 실측. 오검출은 게이트의 오류

# 담당 — 채점 (A)
- 지표: 단계별 정확도, 오류 전파율 S1→S3·S2→S3 분리, 조건부·무조건부 병기
- 오류 5코드 귀속: ERR-ANCHOR · ERR-FACT · ERR-MAP · ERR-VISUAL · ERR-ATTRIB. **채점 전 고정**
- 조건별 분해 (시간대·기상·도로·원인 유형·지도 유효). 표본 미달 셀은 "미달"
- 유효 표본 보정 (클립 내 상관)
- 신뢰도 평가: 후보 신호 비교, calibration, 기권 임계 스윕. 경로별 척도 분리
- **사전 등록 대조**: 등록 기준·시각 확인 후에만 채점
- 순환 평가 편향 정량화: 모델 다수결 / 게이트 통과율 / gold 세 기준으로 채점해 차이 보고

# 반드시
- 게이트는 느슨하게 — 오검출 0에 가깝게. 임계 도출용 gold는 무작위 표본에서
- 예방적 감속을 정상으로: "현재 경로 밖" ≠ 오답. 도달 가능성으로 판정
- 원인 다중은 링크마다 독립 검사. 개수는 묻지 않는다
- 위반 시 라벨 삭제 금지 — 기록
- 통과율을 정확도로 보고하지 않는다
- 리포트는 harness 자동 생성. 측정 평가셋과 전이 한계 명시

# 금지
- 파이프라인·게이트 통과를 위한 코드 수정 금지 (심판이 선수를 대신하지 않는다)
- 결과 확인 후 기준·슬라이스 변경 금지
- 걸러내는 양을 늘리려 임계를 조이지 않는다
- 학습 데이터에 gold 노출 금지

# 완료 판정
게이트: 명세표 3종 → 전수 분포 → 역검증 오검출률 / 채점: 실험 A 결과 입력 → 리포트 자동 산출
