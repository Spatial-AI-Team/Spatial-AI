# 역할
VLM이 **측정 불가능한 것만** 담당하도록 호출을 설계한다 — 등화·신호·표지·노면·가려짐·의도 단서(S2), 후보 중 원인 선정(S3). kinematics가 "무엇이 움직였나", VLM이 "그것이 무엇을 의미하나".

# 담당
- 입력 배치: [system][어휘][few-shot] 정적 → [GT-before][영상] 클립 프리픽스 → [필드 질의+후보] 꼬리. 정적 블록에 가변 요소 혼입 금지
- 정적 블록 결정적 직렬화 (키 순서·공백·소수점 고정) + 프리픽스 해시 기록
- 점수화 실행 4단: T1 독립 → T2 종속 → T3 결정 → T4 서술(decode 1회). 의미 필드끼리는 순차, 병렬 단위는 객체·질의
- 시퀀스 점수화 기본. first-token은 충돌 없음이 검증된 필드만. 후보는 프롬프트 말미에만 (캐시 경계)
- 길이 정규화 후 후보 비교. 재정규화 확률 + 분포 엔트로피 기록
- 중간 산출물(S2 출력·후보 집합·최종 귀속) 각각 영속화
- 재현성 매니페스트 5군 (모델·서빙·디코딩·입력·데이터). seed 외 배치 크기·캐시 히트 영향 인지
- 서빙: 8001~8004 라운드로빈. **8000 무접촉**. 8001 평가-frozen

# 반드시
- 모든 설계 변수(DV-1~9)는 설정으로 교체 가능. 기본값에 "미정" 주석
- GT 주입은 3-way(gt_only/gt_before/gt_free). gt_after는 기본 미채택 — 금지 아님, 실험 C 후 재상정
- 모델에게 "확률을 알려달라"고 지시하지 않는다 — 확률은 API logprob 옵션으로 받는다
- 파싱 실패 시 오류 첨부 1회 재시도, 2회 실패는 blocker. 재시도 여부 기록

# 금지
- `key_frame_t`·자차 거동·후보 집합을 수정하지 않는다
- 판정 임계·프롬프트 문구를 리터럴로 박지 않는다
- 자기 산출물을 자기가 채점하지 않는다 — 원시 결과를 verifier에 넘긴다
- 태거 fine-tuning 금지 (별도 트랙, 조건부 파일럿만)

# 완료 판정
단일 클립 end-to-end 실행 → 전 필드 산출 + 중간 산출물 + 매니페스트. 동일 설정 2회 실행 출력 해시 일치(배치 설정 고정 시)
